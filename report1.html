// HTMLタグ一覧
文書構造
基本<!DOCTYPE html>

HTML5 文書であることをブラウザに宣言する。必ず1行目に書く。

<!DOCTYPE html>
基本<html>

ページ全体を囲むルート要素。lang 属性で言語を指定する。

<html lang="ja">…</html>
基本<head>

タイトルや文字コードなど、ページの情報（メタ情報）を入れる場所。画面には表示されない。

<head> <meta charset="UTF-8"> <title>ページタイトル</title> </head>
基本<body>

画面に表示されるコンテンツをすべてここに書く。

<body>…表示内容…</body>
見出し・テキスト
見出し<h1> 〜 <h6>

見出しタグ。h1 が最大・最重要、h6 が最小。1ページに h1 は1つが基本。

<h1>大見出し</h1> <h2>中見出し</h2> <h3>小見出し</h3>
テキスト<p>

段落（paragraph）。本文テキストの基本単位。

<p>ここに本文テキストを書く。</p>
テキスト<span>

インライン要素。テキストの一部だけスタイルを変えたいときに使う。

<p>ここだけ<span style="color:red;">赤くする</span>。</p>
テキスト<strong>

重要な語句を太字にする。見た目だけでなく意味的な強調も持つ。

<p>これは<strong>重要</strong>なポイント。</p>
テキスト<br>

強制改行。閉じタグなし。テキスト途中で改行したいときに使う。

<p>1行目<br>2行目</p>
リンク・メディア
リンク<a>

リンク（anchor）。href にURLを指定する。別タブで開くには target="_blank" を追加。

<a href="page.html">リンクテキスト</a>
メディア<img>

画像を表示する。src にファイルパス、alt に代替テキスト（必須）を指定。閉じタグなし。

<img src="photo.jpg" alt="写真の説明">
レイアウト
ブロック<div>

汎用のブロック要素。レイアウトのグループ化に使う。意味を持たないコンテナ。

<div style="display: flex;"> …コンテンツ… </div>
セマンティック<header>

ページやセクションのヘッダー部分。ロゴ・ナビなどを入れる。

<header>…ナビ・ロゴ…</header>
セマンティック<main>

ページのメインコンテンツ。1ページに1つだけ使う。

<main>…主要コンテンツ…</main>
セマンティック<section>

意味のあるひとまとまりのコンテンツを区切るタグ。見出しとセットで使う。

<section> <h2>セクション名</h2> <p>内容</p> </section>
セマンティック<footer>

ページの末尾。コピーライトやリンクなどを入れる。

<footer>© 2025 GREEN GRID</footer>
セマンティック<nav>

ナビゲーションリンクをまとめるタグ。メニューバーなどに使う。

<nav> <a href="index.html">Home</a> </nav>
リスト
リスト<ul>

順序なしリスト（箇条書き）。<li> を子要素に持つ。

<ul> <li>りんご</li> <li>みかん</li> </ul>
リスト<ol>

順序ありリスト（番号つき）。手順や順位を表すときに使う。

<ol> <li>まず〇〇する</li> <li>次に△△する</li> </ol>
表
テーブル<table>

表全体を囲む。<thead>（ヘッダー）・<tbody>（本体）・<tr>（行）・<th>/<td>（セル）で構成する。

<table> <thead><tr><th>名前</th><th>説明</th></tr></thead> <tbody><tr><td>div</td><td>汎用ブロック</td></tr></tbody> </table>
フォーム
フォーム<form>

入力フォームを囲むタグ。action に送信先、method に送信方法（GET/POST）を指定。

<form action="send.php" method="POST"> …入力欄… </form>
フォーム<input>

入力欄。type で種類を変える（text / email / password / checkbox など）。閉じタグなし。

<input type="text" placeholder="名前を入力"> <input type="email" placeholder="メールアドレス">
フォーム<textarea>

複数行のテキスト入力欄。rows で高さの目安を指定できる。

<textarea rows="5" placeholder="メッセージを入力…"></textarea>
フォーム<button>

ボタン。type="submit" でフォーム送信、type="button" でJSと連携するときに使う。

<button type="submit">送信する</button>
メタ・リソース
メタ<meta>

文字コード・viewport・SNSカードなどの設定を書く。<head> 内に置く。閉じタグなし。

<meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0">
リソース<link>

外部CSSやフォントを読み込む。<head> 内に書く。閉じタグなし。

<link rel="stylesheet" href="style.css">
スクリプト<script>

JavaScriptを書く・読み込む。</body> の直前に置くのが基本。

<script src="app.js"></script> <script>console.log("hello");</script>
リソース<style>

HTMLファイル内に直接CSSを書く。<head> 内に置く。

<style> body { background: #F2F8E8; } </style>
